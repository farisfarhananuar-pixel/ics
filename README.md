# TEQ Technologies – Interactive References

**BKALK3063 Integrated Case Study | Universiti Utara Malaysia**

An interactive, mobile-friendly references page for the TEQ Technologies case study poster. Features red-themed design with filter buttons by category and live search.

## Features
- Filter references by: Venture Capital · DCF/Valuation · India/Startup · Market/Strategy
- Live search by author, title, or topic
- "Show All" toggle — shows 4 at a time by default
- Fully responsive, mobile-friendly
- Red/dark theme matching TEQ poster design

## Deploy to Railway

1. Push this repo to GitHub
2. Go to [railway.app](https://railway.app) → New Project → Deploy from GitHub
3. Select this repo — Railway auto-detects Node.js
4. Done! Copy the generated URL and use it as your QR code link.

## Local Development

```bash
npm install
npm start
# open http://localhost:3000
```
